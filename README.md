# Internet Speed Test Using Tkinter

A simple Internet Speed Test desktop application developed using Python and Tkinter.

The application checks the current internet connection speed and displays:

* Ping
* Download Speed
* Upload Speed

## Technologies Used

* Python
* Tkinter
* Speedtest
* Pillow / Tkinter PhotoImage

## Features

* Simple graphical user interface
* Check internet download speed
* Check internet upload speed
* Display ping in milliseconds
* Display download speed in Mbps
* Display upload speed in Mbps
* Custom GUI images and icons

## Required Library

Install the Speedtest library using:

```bash
pip install speedtest-cli
```

## How to Run

1. Install Python.
2. Install the required library:

```bash
pip install speedtest-cli
```

3. Download or clone this repository.
4. Make sure the `Speedtest` folder is present in the same directory as the Python file.
5. Run:

```bash
python "Internet Speedtest App.py"
```
